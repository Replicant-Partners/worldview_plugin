# Changelog

All notable changes to the Worldview Plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-01-27

### Added
- Initial release of worldview plugin
- WorldviewGraph class for ontology management
- PatternObserver for automatic pattern detection
- Continuous evolution loop with configurable intervals
- Mermaid ER diagram serialization
- Semantic cardinality system
- Auto-apply for high-confidence suggestions
- Suggestion queue for medium-confidence patterns
- Three registered actions: GET_WORLDVIEW, QUERY_WORLDVIEW, GET_SUGGESTIONS
- Comprehensive documentation and examples
- Type definitions for all core interfaces
- Basic entity extraction from text
- Cardinality inference from observation patterns
- Confidence scoring for suggestions

### Features
- Entities with attributes and observation tracking
- Relationships with cardinality and confidence
- Six cardinality types with semantic implications
- Query interface for entities and relationships
- Git-friendly Mermaid storage format
- Configurable thresholds and intervals
- Clean plugin lifecycle management

### Development
- TypeScript implementation
- Complete type safety
- Modular architecture
- Extension points for future enhancements
- Test examples
- Usage examples
- Development guide
